# 🐉 Tamagotchi 1.0 - RCM

Um Tamagotchi feito em **Python** com **pygame**, com visual pixel art 2D inspirado nos bichinhos virtuais clássicos. O pet anda de um lado para o outro da tela e evolui ao longo de várias fases da vida.

> Projeto de estudo desenvolvido durante o curso de Análise e Desenvolvimento de Sistemas (ADS).

## ✨ Funcionalidades

- Animações em pixel art com spritesheets (6 frames por estágio)
- O pet caminha de um lado ao outro da tela e espelha o sprite ao voltar
- O ovo fica balançando no lugar
- Seis estágios de vida, cada um com um dragão diferente:
  1. 🥚 Ovo
  2. 🍼 Bebê
  3. 🧒 Criança
  4. 🧑 Adolescente
  5. 🧔 Adulto
  6. 👴 Ancestral

## 🛠️ Tecnologias

- [Python 3](https://www.python.org/)
- [pygame](https://www.pygame.org/)

## 📦 Instalação

1. Clone o repositório:

```bash
git clone https://github.com/rdacostamendes/tamagotchi.git
cd tamagotchi
```

2. Instale o pygame:

```bash
pip install pygame
```

## ▶️ Como executar

```bash
python Tamagotchi.py
```
